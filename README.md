## 1. 프로젝트 설명

행정 체납·의료 데이터(진료 정보, 만성질환+급여현황)와 일상 생활 데이터(전력·가스 사용량, 통신 데이터)를 결합해 사회적 고립 및 위기 징후가 나타나는 가구를 조기에 탐지하고, 사전에 예방 조치를 취할 수 있도록 지원하는 Streamlit 웹 애플리케이션입니다.

- **의약품 및 만성질환 주기 분석 (Tab 1~5):** 2025년 1~12월 의약품 처방 시계열 추이, 전국 시도별 환자 분포 지도(CartoDB Positron + Folium), 연령대별 처방 변동계수(CV), 진료과목별 주기, 서울 자치구별 만성질환 진료 및 평균 내원 간격(일)을 분석해 기본 위기 기초점수를 산출합니다.
- **전력·가스 사용 급감 모니터링 (Tab 6):** 서울 25개 자치구 평균 사용량 기준선 대비 최근 전력·가스 급감률을 시뮬레이션하여 위기 점수에 따라 `위험(Red)` · `주의(Yellow)` · `정상(Green)` 등급을 분류합니다.
- **모바일 통신·이동 고립도 분석 (Tab 7):** 기지국 기반 통신 데이터(`최종합본데이터3.xlsx`)의 자치구·성별·연령대별 평균 통화량, 데이터 사용량, 문자량을 분석해 사회적 고립 상태를 교차 검증합니다.
- **4-Way 통합 AI 시뮬레이터 (Tab 8):** 의료 처방주기 이탈, 전력·가스 급감률, 돌봄 바우처 연속 누락, 통신·데이터 급감률의 4개 도메인 지표를 통합하여 최종 위기 점수(0~100점)와 판정 등급(Red/Yellow/Green)을 산출하고, 도메인별 기여도를 분해한 **XAI(SHAP) 원인 리포트**를 제공합니다.

## 3. 주제 선택 이유

- **사후 발굴의 시차 극복:** 현재 보건복지부에서 실행하고 있는 위기가구 발굴 시스템은 체납·연체가 발생한 이후 수개월이 지나서야 위험 가구를 포착하고 있습니다. 고독사 예방과 취약계층 보호를 위해서는 위기 징후 데이터를 최대한 빠르게 잡아내는 것이 중요하다고 판단했습니다.
- **복지 행정 효율화:** 데이터 기반의 선제적 조기 경보 체계를 구축하여 복지 담당 공무원들의 업무 과부하를 줄이고, 고독사를 실질적으로 예방하기 위해 본 프로젝트를 기획했습니다.

### 데이터 결합 및 점수 산출 구조

| 구분 | 활용 데이터 | 분석 방식 및 역할 |
| :--- | :--- | :--- |
| **정적 / 주기 데이터** | 진료과목별 진료정보 + 만성질환 + 급여현황 + 의약품 처방주기 | 연령대별 처방 변동계수(CV) 및 평균 내원 간격 분석 → **기본 위기 기초점수 산출** |
| **동적 시계열 데이터** | 통신 사용량, 전력 사용량, 가스 사용량 | 1주 단위의 활동 감소량 및 계절 대비 패턴 이상 분석 → **기본 위기점수에 가산 점수 부여** |

- **대용량 전처리 최적화:** 12개월 분량의 의약품 CSV 데이터(약 300MB 이상)를 로드할 때 `@st.cache_data`와 연월·연령·성별·시도 단위 사전 집계를 적용하여 웹 대시보드 응답 속도를 확보했습니다.
- **인코딩 및 경로 호환:** 다양한 공공데이터 파일 인코딩(`utf-8`, `cp949`, `utf-8-sig`, `euc-kr`)을 자동 판별하는 `read_csv_safe()` 유틸과 루트·`data/` 디렉터리 자동 탐색 로직을 적용했습니다.

### AI 활용 방안 및 목표 (`XGBoost + SHAP`)

- **현재 구현 (프로토타입 시뮬레이터):** 실측 가구 단위 결합 데이터 확보의 제약으로, 대시보드 Tab 8에서는 도메인별 기여도 분해 로직을 검증할 수 있는 인터랙티브 프로토타입 시뮬레이터로 구현했습니다.
- **실제 도입 목표:** 현장 도입 시에는 4개 도메인(의료·에너지·돌봄·통신) 간의 비선형 상호작용(예: 여름철 냉방비 절감 vs 실제 위기 상황에서의 급감 구분)을 정교하게 학습하기 위해 **`XGBoost + SHAP`** 모델을 적용하여, AI가 이상치를 탐지하고 판정 근거를 설명할 수 있도록 하는 것이 목표입니다.

### 데이터 분석 개선 및 현장 도입 방향

1. **1단계 (현재 — 공공 집계 기반 선별):** 공공 개방 집계 데이터를 활용하여 서울 자치구별 고위험 군집과 취약 패턴을 우선 선별합니다.
2. **2단계 (향후 — 가구 단위 실측 연동):** **사회보장급여법** 근거 또는 **고위험 독거가구 사전 동의 기반(지자체 스마트돌봄 시범사업)**을 마련하고, **가명정보 결합전문기관**을 통해 단계적으로 연동하여 의료·전력·가스·통신 데이터를 실제 가구 단위로 결합할 계획입니다.
