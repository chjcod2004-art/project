팀명:복세편살

프로젝트 주제:  의료·돌봄·에너지·통신 4-Way 통합 위기가구 조기 경보 시스템

프로젝트 설명: 행정 체납 데이터(진료 정보,만성질환+급여현황)와 일상 데이터(가스 사용량,통신 데이터)를 결합해서 위기 징후가 나타나는
              위기 가구들을 찾아내서 빨리 사전 예방을 할 수 있게 만든 프로젝트입니다

AI 사용 : 실측 결합 데이터 확보의 제약으로 프로토타입 시뮬레이터로 구현하였고,실제 도입 시에는 
4개 도메인의 비선형 상호작용(예: 여름철 냉방비 절감 vs 실제 위기 급감 구분)을 학습하기 위해 XGBoost + SHAP을 적용시켜 AI가 학습하여
이상치를 찾아낼 수 있도록 하는것이 목표입니다

주제 선택 이유 : 현재 보건복지부에서 실행하고 있는 시스템은 체납,연체가 발생한 후에 수개월후에 위험가구를 포착하고 있다
                따라서 이런 고독사와 취약계층의 보호를 위해 최대한 빠르게 데이터를 잡아내는것이 중요하다 생각했습니다 
                추가로 공무원들의 업무 과부하를 줄이고 고독사를 줄이기 위한 프로젝트입니다
                
데이터 분석 내용:  진료과목별 진료정보 + 만성질환 + 급여현황 -> 정적/주기 데이터 -> 기본 위기 기초점수 산출
                  통신,전력,가스 ->동적 시계열 데이터 -> 1주의 활동 감소량 , 계절 대비 패턴 이상 분석 -> 기본 위기점수에 점수 추가

데이터 분석 개선 방향: 공공 개방 집계 데이터로 자치구별 고위험 군집을 선별하고, 현장 도입은
사회보장급여법 근거 또는 고위험 독거가구 사전 동의 기반(지자체 스마트돌봄 시범사업) + 가명정보 결합전문기관을 통해 단계적으로
연동하여 의료,전력,통신 데이터를 가구 단위로 합칠 생각입니다
